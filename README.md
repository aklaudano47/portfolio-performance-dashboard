# Portfolio Performance & Risk Dashboard

This repository contains portfolio analytics and ETF comparison projects focused on evaluating asset performance, volatility, drawdowns, correlations, and benchmark-relative risk behavior using Python financial analytics workflows.

## Project Overview

The project evaluates selected equities and ETFs across several portfolio-risk dimensions, including:

* annualized return;
* annualized volatility;
* Sharpe ratio;
* maximum drawdown;
* rolling portfolio behavior;
* and cross-asset correlation structure.

The analysis emphasizes practical portfolio analytics concepts commonly used in investment performance, risk management, and asset-allocation evaluation.

## Included Analyses

### Portfolio Performance & Risk Dashboard

Analyzed:

* AAPL
* MSFT
* JPM
* JNJ
* XOM
* SPY benchmark

Metrics and visualizations include:

* normalized portfolio performance;
* drawdown analysis;
* correlation matrices;
* risk-adjusted return comparisons.

### ETF / Sector Comparison Analysis

Compared:

* XLK
* QQQ
* SPY
* XLF

The project evaluates:

* sector-level return behavior;
* volatility tradeoffs;
* benchmark-relative risk;
* and downside exposure during market stress periods.

## Key Findings

* ExxonMobil (XOM) generated the strongest risk-adjusted equity performance over the evaluated horizon.
* Technology-focused ETFs (XLK, QQQ) produced superior returns but experienced significantly larger drawdowns and volatility.
* Broader benchmark exposure (SPY) and defensive sectors demonstrated improved downside stability during market stress periods.
* Correlation analysis highlighted diversification tradeoffs across sectors and asset classes.
